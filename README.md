# Vyron

A mobile app that connects people through real-life meetups 
and opportunities — bridging digital discovery and physical 
connections.

## Stack
- **Frontend:** Flutter
- **Backend:** Supabase
- **Development:** AI-assisted coding with Claude Code

## Product journey
1. Concept & market research
2. UX wireframes & UI design
3. Prototype built with Adalo (UX validation)
4. Full rebuild in Flutter + Supabase (current version)

Final development stage — preparing for launch.
